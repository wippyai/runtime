## Foundational causes and status

- Same-definition wrapper methods used a catalog-specific recursive `self` identity. Typed method receivers now use `Self`.
- Conformance counted all non-optional parameters as required, including a trailing `any` that accepts omitted Lua nil. It now computes minimum arity from nil acceptance.
- An empty incomplete open record indexed through a known string fell back to nil. It now yields unknown, matching JSON Schema additional properties.
- Captured annotated records lost dominating nested-field guards at closure creation. The checker now carries path narrowings when no later direct write invalidates them.
- Three poll binding output diagnostics arose when a partial inferred record was treated as proof that an unlisted field was absent. Conformance now requires a complete record for that proof and checks direct literal returns separately, including dotted Lua definitions such as `function M.resolve`; this preserves the genuine scope-resolver violation.
- The nine listed cron diagnostics arose from two layers: flow lost the enum proof carried by a literal-array validation flag, and nested mutable-record widening rejected nil-valued filter keys against optional schema properties. Both have reduced regression tests; the final cold gate verifies the target copies.
- The two kb10 test diagnostics arose because inferred error-return forwarding skipped method-call AST nodes. Typed `open` now declares its error-return relation, and forwarding recognizes method calls and their overload intersections; a fresh kb10 lint probe removes both warnings.
- Two later interface-assignment diagnostics arose because structural subtyping resolved `Self` in the interface method but left `Self` unresolved in the record method. Both sides now resolve against the implementing record; the reduced recursive-record test and the `contract.Contract` assignment test failed before the fix and pass after it.

## Error versus string?

`error` and `Error` denote `typ.LuaError`, an interface value with error methods. It is not a subtype of `string?`; none of the five `wippy.llm` return annotations can promise `string?` for the contract error slot. Keep the architect rule and change the Lua annotation to `Error?` when those sources can be edited. The seven-argument `track_usage` calls also need one request object under positional input semantics.
